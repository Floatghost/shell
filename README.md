# why❓ Rust🦀
because powershell is written in C#
- ❌ C# uses gc which is not optimal for a shell
- ❌ Lacks modern error handling
- ❌ Not memory-safe
- ❌ No fearless concurrency
- ❌ Not written in Rust

# Features ✨

- 🚀 **Blazingly fast** - Outputs your input at unprecedented speeds
- 🛡️ **Memory safe** - No segfaults, guaranteed!
